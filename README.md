# ECE414FinalProj
    Final Reinforcement Learning Project for ECE 414

## PNG Results directory
    Final results for the agent will be plotted/screenshotted and saved to the PNG directory

## Requirements Download
    Run:
        venv/bin/python -m pip install -requirements.txt

## Makefile 
    Clean and run files in order:
        make clean ; make

## Run Command
    venv/bin/python src/main.py
        or 
    make
